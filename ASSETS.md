# Карта и визуальные материалы

Используются исходные файлы пользователя в корне проекта. Vite импортирует их с хэшами; переносить или дублировать их в public не требуется.

- `map.png`: подложка без встроенных UI-подписей.
- `separated regions.png`: отдельный overlay. Его родной размер, как у карты, — 1536 × 1024.
- `builds.png`: атлас зданий. LandmarkLayer показывает отдельные здания через SVG viewBox и контурные clipPath. Исходный PNG не изменён. При замене на отдельные прозрачные PNG нужно обновить landmarks.ts и LandmarkLayer.
- `icons.png`: атлас иконок направлений; используется через SVG viewBox.
- `example.png`: визуальный референс, не встраивается в интерфейс.

Все 7 слоёв расположены в одном map-world. Zoom и pan применяются к общему родителю. CSS perspective + rotateX/rotateZ создают вид под углом, обратный поворот оставляет здания и метки вертикальными. 2D отключает наклон. Никакого WebGL, картографического SDK или 3D-движка нет.

## Ограничения исходного overlay

В изображении 6 цветных зон, в игровом датасете 5 районов. Для иллюстративного демо зелёная и оранжевая зоны объединены в игровой Алматы; синяя — Сарыарка, фиолетовая — Байконур, жёлтая — Нура, красная — Есиль. Это сопоставление для UI, не официальные границы. Контур overlay не зарегистрирован географически к подложке: общий размер сохраняет синхронность при масштабировании, но не исправляет исходное несовпадение береговой линии. На экране указаны условные границы.

Для точной карты требуется согласованный комплект base-map + overlay с одинаковой проекцией/кадрированием и именованными 5 районами. При замене обновить обе картинки, `mapGeometry.ts`, координаты в `districts.ts` и `landmarks.ts`.

Попытка imagegen удалить фон из атласа не дала чистой прозрачности. Этот сгенерированный вариант не используется; приложение отображает оригинальные материалы с кодовыми масками.
