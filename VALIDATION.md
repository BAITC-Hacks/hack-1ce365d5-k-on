# Проверка оптимизации — 2026-09-23

## Что изменено

- Убрана вторая копия вариантов из контекста модели; JSON передаётся компактно.
- Сохранение памяти проверяет версию файла и использует эксклюзивную блокировку:
  устаревший чат не перезаписывает новый. Неизменённый файл не записывается повторно.
- Загрузка памяти использует один каталог для всех проверок вместо повторного чтения
  для каждого варианта. Проверяется порядок пар сообщений и уникальность ID вариантов.
- Разбор JSON ограничивает размер и отвергает дубли полей, NaN, Infinity и переполнение
  чисел с плавающей точкой. Некорректный ответ API превращается в понятную ошибку.
- Обработаны вложенный таймаут и разрыв соединения; HTTP-ошибки закрывают ответ.
- Исправлен вывод Score для рассчитанных движком вариантов.
- Добавлены установка wheel, команда `akim-advisor`, stdin и несовместимость режимов CLI.
- Подготовлены GitHub Actions, Dependabot и шаблон pull request.

`python3 -m tools.benchmark_payload` сравнивает текущий контекст с прежним форматом:

токены, стоимость, качество ответа или сетевую задержку.

## Что ещё не проверено

- Локальная проверка выполнена на Python 3.14. Статус удалённой матрицы Python 3.10–3.14
  смотрите в [GitHub Actions ветки logic](https://github.com/BAITC-Hacks/hack-1ce365d5-k-on/actions?query=branch%3Alogic).
- Живые ответы OpenAI не проверялись. Адаптер протестирован на подставных HTTP-ответах,
  включая отказ, неполный ответ, повреждение структуры и сетевые ошибки.
- Движок расчёта по-прежнему подключается извне. В тестах используются только
  синтетические баллы; новые игровые формулы не добавлялись.
- После аварийного завершения процесса во время сохранения может остаться `.lock`.
  Порядок восстановления описан в README. Блокировка рассчитана на локальную файловую систему.
